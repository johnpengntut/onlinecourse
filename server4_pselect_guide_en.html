Multi-Process TCP Server & POSIX Signal-Safe Architecture

Starting from the hidden pitfalls of classic server4_2.c, this guide uses architectural diagrams and an interactive state simulator to explain SIGCHLD loop reaping, how pselect() atomic signal-mask swapping eliminates Lost Wakeup race conditions, and how parent/child processes isolate file descriptors and signals after fork().

Diagnosis 1. Why Does Legacy server4_2.c Need Refactoring?

The original server4_2.c follows a classic process-per-connection concurrency model—calling fork() for each incoming client—and relies on a single signal(SIGCHLD, SIG_IGN) call to handle child termination. While sufficient for a minimal textbook demo, it suffers from four critical systems-programming flaws in production environments:

Design Area Original server4_2.c Hidden Risks & Consequences Refactored Solution
Signal Registration API Uses legacy signal(SIGCHLD, SIG_IGN) Semantics vary across historical Unix platforms, and ignoring SIGCHLD prevents logging child exit statuses or running custom cleanup hooks. Adopt POSIX sigaction() with SA_NOCLDSTOP and an explicit non-blocking reaping loop.
Graceful Shutdown Unconditional while(1) loop; ignores SIGINT / SIGTERM Pressing Ctrl+C or receiving a service-stop signal kills the process abruptly without closing the listening socket or running cleanup code. Install an on_stop handler that sets a volatile sig_atomic_t stop_server flag to exit the loop cleanly.
Race Condition Checking a flag right before calling blocking accept() If a signal arrives after checking the flag but before entering accept(), the wakeup is lost and the server hangs indefinitely. Block signals with sigprocmask(SIG_BLOCK) during the check, and use pselect() to atomically unblock and wait.
FD Reference Leak Child process never closes inherited server_sockfd Every active child holds a reference to the listening socket, keeping the port open if the parent restarts or shuts down while clients are active. Immediately call close(server_sockfd) and restore default signals in the pid == 0 child branch.

Mechanism 1 3. SIGCHLD & Reaping Zombie Processes Safely

When a child process terminates via exit(0), the Linux kernel does not immediately destroy its process control block (task_struct). Instead, it retains the child's exit status until the parent collects it via wait() or waitpid(). During this window, the terminated child exists as a Zombie Process.

Why Must the Handler Loop with while (waitpid(-1, NULL, WNOHANG) > 0)?

A common bug is calling waitpid(-1, NULL, WNOHANG) only once inside on_sigchld. Under concurrent load, this leaks zombie processes because standard POSIX signals do not queue (Signal Coalescing):

  • Single Pending Bit per Signal: The kernel tracks pending standard signals using a bitmask—one bit per signal number. If three child processes exit simultaneously while SIGCHLD is blocked in the parent, the kernel sets the SIGCHLD pending bit to 1 only once.
  • One Handler Invocation for Multiple Exits: When pselect() unblocks signals, on_sigchld runs only once. Without a while loop draining all exited children, the other two children remain zombies permanently.
  • Preserving errno: When no more terminated children remain, waitpid() returns -1 and sets the thread-local errno to ECHILD. Saving int saved_errno = errno; upon entry and restoring it before returning prevents corrupting error checks in the main loop.

Implementation 6. Complete Refactored Code & Walkthrough (server4_clean.c)

Below is the complete, warning-free POSIX C11 implementation incorporating all signal-safety protections, including <sys/select.h> and FD_SETSIZE bounds checks. Compile with: gcc -std=c11 -Wall -Wextra -O2 server4_clean.c -o server4_clean.

server4_clean.c — Signal-safe multi-process TCP server with pselect() & SIGCHLD reaping 
#define _POSIX_C_SOURCE 200809L

#include <errno.h>
#include <netinet/in.h>
#include <signal.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/select.h>
#include <sys/socket.h>
#include <sys/types.h>
#include <sys/wait.h>
#include <unistd.h>

static volatile sig_atomic_t stop_server = 0;

/* Handle SIGINT / SIGTERM: only set the atomic shutdown flag */
static void on_stop(int sig) {
    (void)sig;
    stop_server = 1;
}

/* Handle SIGCHLD: reap all terminated child processes and preserve errno */
static void on_sigchld(int sig) {
    (void)sig;
    int saved_errno = errno;
    while (waitpid(-1, NULL, WNOHANG) > 0) {
        /* Continue reaping until no more terminated children remain */
    }
    errno = saved_errno;
}

int main(void) {
    /* 1. Install POSIX sigaction signal handlers */
    struct sigaction sa;
    sigemptyset(&sa.sa_mask);

    sa.sa_handler = on_sigchld;
    sa.sa_flags = SA_NOCLDSTOP; /* Ignore stopped/continued child transitions */
    if (sigaction(SIGCHLD, &sa, NULL) == -1) {
        perror("sigaction(SIGCHLD)");
        return EXIT_FAILURE;
    }

    sa.sa_handler = on_stop;
    sa.sa_flags = 0;
    if (sigaction(SIGINT, &sa, NULL) == -1 || sigaction(SIGTERM, &sa, NULL) == -1) {
        perror("sigaction(SIGINT/SIGTERM)");
        return EXIT_FAILURE;
    }

    /* 2. Block critical signals so pselect() can atomically unblock and wait */
    sigset_t block_mask, orig_mask;
    sigemptyset(&block_mask);
    sigaddset(&block_mask, SIGCHLD);
    sigaddset(&block_mask, SIGINT);
    sigaddset(&block_mask, SIGTERM);
    if (sigprocmask(SIG_BLOCK, &block_mask, &orig_mask) == -1) {
        perror("sigprocmask");
        return EXIT_FAILURE;
    }

    /* 3. Create, configure, and bind the TCP listening socket */
    int server_sockfd = socket(AF_INET, SOCK_STREAM, 0);
    if (server_sockfd == -1) {
        perror("socket");
        return EXIT_FAILURE;
    }

    if (server_sockfd >= FD_SETSIZE) {
        fprintf(stderr, "server_sockfd (%d) exceeds FD_SETSIZE (%d)\n",
                server_sockfd, FD_SETSIZE);
        close(server_sockfd);
        return EXIT_FAILURE;
    }

    int opt = 1;
    if (setsockopt(server_sockfd, SOL_SOCKET, SO_REUSEADDR, &opt, sizeof(opt)) == -1) {
        perror("setsockopt(SO_REUSEADDR)");
        close(server_sockfd);
        return EXIT_FAILURE;
    }

    struct sockaddr_in server_address = {
        .sin_family = AF_INET,
        .sin_addr.s_addr = htonl(INADDR_ANY),
        .sin_port = htons(9734)
    };

    if (bind(server_sockfd, (struct sockaddr *)&server_address, sizeof(server_address)) == -1) {
        perror("bind");
        close(server_sockfd);
        return EXIT_FAILURE;
    }

    if (listen(server_sockfd, 128) == -1) {
        perror("listen");
        close(server_sockfd);
        return EXIT_FAILURE;
    }

    /* 4. Main event loop: wait synchronously for connections or signals */
    while (!stop_server) {
        fd_set readfds;
        FD_ZERO(&readfds);
        FD_SET(server_sockfd, &readfds);

        printf("server waiting\n");
        int ready = pselect(server_sockfd + 1, &readfds, NULL, NULL, NULL, &orig_mask);
        if (ready == -1) {
            if (errno == EINTR) {
                /* Interrupted by a signal; loop back to check stop_server */
                continue;
            }
            perror("pselect");
            break;
        }

        if (!FD_ISSET(server_sockfd, &readfds)) {
            continue;
        }

        struct sockaddr_in client_address;
        socklen_t client_len = sizeof(client_address);
        int client_sockfd = accept(server_sockfd,
                                   (struct sockaddr *)&client_address,
                                   &client_len);
        if (client_sockfd == -1) {
            if (errno == EINTR || errno == ECONNABORTED) {
                continue;
            }
            perror("accept");
            continue;
        }

        pid_t pid = fork();
        if (pid == -1) {
            perror("fork");
            close(client_sockfd);
        } else if (pid == 0) {
            /* Child process: close listening socket and restore default signals */
            close(server_sockfd);

            struct sigaction sa_dfl;
            sigemptyset(&sa_dfl.sa_mask);
            sa_dfl.sa_handler = SIG_DFL;
            sa_dfl.sa_flags = 0;
            sigaction(SIGINT, &sa_dfl, NULL);
            sigaction(SIGTERM, &sa_dfl, NULL);
            sigaction(SIGCHLD, &sa_dfl, NULL);
            sigprocmask(SIG_SETMASK, &orig_mask, NULL);

            char ch;
            if (read(client_sockfd, &ch, 1) == 1) {
                sleep(5);
                ch++;
                if (write(client_sockfd, &ch, 1) == -1) {
                    perror("write");
                }
            }
            close(client_sockfd);
            exit(EXIT_SUCCESS);
        } else {
            /* Parent process: close client socket now handled by the child */
            close(client_sockfd);
        }
    }

    printf("\nShutting down server...\n");
    close(server_sockfd);
    return EXIT_SUCCESS;
}

Key Implementation Walkthrough

#define _POSIX_C_SOURCE 200809L & <sys/select.h>
Enables POSIX.1-2008 declarations under strict -std=c11 compilation, exposing sigaction, sigprocmask, and pselect, while <sys/select.h> provides fd_set, FD_ZERO, and FD_SET.
static volatile sig_atomic_t
sig_atomic_t guarantees single-instruction atomic reads and writes without torn values, while volatile prevents compiler optimizations from caching stop_server in a register across loop iterations.
SO_REUSEADDR Socket Option
Allows the server to immediately rebind port 9734 after a restart even when previous connections remain in the TCP TIME_WAIT state, preventing bind: Address already in use failures.
if (errno == EINTR) continue;
When a child exits (SIGCHLD) or an administrator presses Ctrl+C (SIGINT), pselect() wakes up and returns -1 with errno == EINTR. Executing continue jumps straight back to while (!stop_server): if SIGCHLD woke it, the server resumes waiting; if SIGINT woke it, the loop exits cleanly.
Architectural Note: Multi-Process (fork) vs. Event-Driven (epoll + signalfd)

The pselect() + fork() model demonstrated here offers strong fault isolation—a crash or blocking operation in one child worker never impacts the parent listener or sibling clients—making it ideal for moderate concurrency. For tens of thousands of simultaneous long-lived connections, modern Linux servers replace fork() with a single-process non-blocking epoll loop paired with signalfd() to consume signals as regular file descriptor events.
