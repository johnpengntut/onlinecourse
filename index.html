Evolution of Select, Poll, and Epoll with Practical Server Refactoring

From fixed-size bitmasks to modern kernel event-driven architectures: a complete breakdown of Linux I/O multiplexing bottlenecks and a step-by-step refactoring of a TCP server integrating signalfd() for race-free signal handling.

Background 1. Why Do We Need I/O Multiplexing?

When building a network server, an application must simultaneously monitor a listening socket for incoming connection requests and multiple client sockets for incoming data. Relying on traditional blocking I/O introduces severe architectural constraints:

  • Single-Process Blocking Dilemma: If a process blocks on accept() waiting for new clients, it cannot read data from already connected clients. Conversely, blocking on read() for one client freezes the entire server for everyone else.
  • Multi-Process / Multi-Thread Overhead (e.g., fork()-per-client): Spawning a dedicated child process per connection is conceptually straightforward, but when concurrent connections scale into the thousands, process creation, memory footprint, and context-switching overhead quickly exhaust system resources.

The core value of I/O multiplexing is enabling a single thread to monitor numerous file descriptors (FDs) through a single system call, sleeping efficiently until at least one descriptor becomes ready for I/O.

Evolution 2. Three Generations: select → poll → epoll

1st Gen: select() O(N) Scan

Uses fixed-size bit arrays (fd_set) to track descriptors. Offers broad cross-platform portability, but suffers from rigid legacy limits.

2nd Gen: poll() O(N) Scan

Replaces bitmasks with a dynamic array of struct pollfd entries, separating requested events from returned events and removing the 1024-FD cap.

3rd Gen: epoll O(1) Ready

Linux-specific stateful architecture storing interest lists in a kernel red-black tree and maintaining a ready list via callbacks to solve the C10K problem.

First Generation: select() Design and Four Bottlenecks

select() requires callers to pass three separate bitmasks—for readability (readfds), writability (writefds), and exceptional conditions (exceptfds)—which the kernel modifies in place to indicate ready descriptors. This creates four major limitations:

  1. Hard 1,024-Descriptor Limit (FD_SETSIZE): On Linux, fd_set is fixed at 1,024 bits. Any descriptor number ≥ 1024 cannot be monitored safely without risking buffer overflow.
  2. Destructive Arguments: Because the kernel overwrites the passed fd_set, the caller must copy a fresh backup of the master set on every single loop iteration (e.g., testfds = readfds).
  3. Repeated Copying and Linear Scanning: The entire fd_set must be copied from user space to kernel space on every call. Upon wakeup, user code must loop from 0 up to max_fd testing every bit—an O(N) scan regardless of how few sockets are active.
  4. Coarse Event Granularity: select() only reports read, write, or exception readiness. A peer disconnect simply surfaces as "readable," forcing an extra ioctl(FIONREAD) or read() == 0 check to detect EOF.

Second Generation: poll() Interface Improvements & Remaining Limits

poll() eliminates bitmasks in favor of a caller-allocated array of struct pollfd structures, each pairing an fd with separate events (input) and revents (output) fields:

  • No Hard Connection Limit: Array capacity is chosen by the developer, bounded only by system memory and ulimit -n.
  • Reusable Descriptor Array: Because input flags (events) and output flags (revents) are decoupled, the array does not need to be reinitialized between iterations.
  • Granular Status Flags: Distinguishes conditions such as POLLIN, POLLOUT, POLLHUP (peer hang-up), POLLERR, and POLLNVAL.
  • Unresolved Kernel Bottleneck: poll() remains stateless. Every call still copies the entire pollfd array from user space to kernel space and linearly scans all N entries inside the kernel (O(N)). With tens of thousands of mostly idle connections, CPU cycles are wasted scanning inactive sockets.

Third Generation: epoll Architecture Revolution (Solving C10K)

Introduced in Linux 2.6, epoll splits descriptor registration from event waiting across three system calls (epoll_create1, epoll_ctl, and epoll_wait), maintaining persistent state inside the kernel:

  • Kernel Red-Black Tree for Interest Management: Descriptors are added, modified, or removed once via epoll_ctl() (O(log N)), eliminating repeated user-to-kernel array copying during epoll_wait().
  • Callback-Driven Ready List for O(1) Retrieval: When network hardware interrupts arrive, kernel callbacks registered on each socket append ready descriptors directly to an internal Ready List. epoll_wait() simply harvests and copies back only the k active events.
  • Level-Triggered (LT) & Edge-Triggered (ET) Modes: Defaults to safe Level-Triggered semantics (continuing to notify while unread bytes remain in the buffer, matching select/poll), while optionally supporting high-throughput Edge-Triggered (EPOLLET) notifications on state transitions.

Integration 4. Unified Event Loop: Why Combine signalfd()?

Production network servers must support graceful shutdown—catching SIGINT (Ctrl+C) or SIGTERM to exit the event loop cleanly and close all open sockets. Relying on traditional asynchronous signal() or sigaction() handlers introduces three classic pitfalls:

  • Interrupted System Calls (EINTR): Asynchronous signals can interrupt blocking calls like select(), poll(), or accept() at arbitrary moments, requiring boilerplate retry loops everywhere.
  • Async-Signal-Safety Constraints: Signal handlers cannot safely call non-reentrant functions like printf(), malloc(), or complex cleanup routines without risking deadlocks.
  • Check-Then-Sleep Race Conditions: If a signal arrives right after the main loop checks a volatile sig_atomic_t stop flag (seeing 0) but just before entering the blocking wait syscall, the wakeup is missed and the server hangs indefinitely.
Core Design Philosophy of signalfd(): Turning Signals into Readable Descriptors

By blocking target signals via sigprocmask(SIG_BLOCK, ...) and creating a descriptor with signalfd(), signals no longer interrupt execution asynchronously. Instead, pending signals queue neatly in the kernel and surface as standard readable events inside poll() or epoll_wait()—unifying network I/O and OS signals in one synchronous, race-free event loop.

Walkthrough 1 5. Baseline Version: server5.c (Classic select())

This baseline program implements a single-process TCP echo-increment server on port 9734 using select() and fd_set to multiplex the listening socket alongside active client connections.

server5.c — Original select() Implementation 
#include <sys/types.h>
#include <sys/socket.h>
#include <stdio.h>
#include <netinet/in.h>
#include <sys/time.h>
#include <sys/ioctl.h>
#include <unistd.h>
#include <stdlib.h>

int main()
{
    int server_sockfd, client_sockfd;
    int server_len, client_len;
    struct sockaddr_in server_address;
    struct sockaddr_in client_address;
    int result;
    fd_set readfds, testfds;

    /* 1. Create TCP socket and bind to port 9734 */
    server_sockfd = socket(AF_INET, SOCK_STREAM, 0);

    server_address.sin_family = AF_INET;
    server_address.sin_addr.s_addr = htonl(INADDR_ANY);
    server_address.sin_port = htons(9734);
    server_len = sizeof(server_address);

    bind(server_sockfd, (struct sockaddr *)&server_address, server_len);

    /* 2. Create listen queue and initialize master readfds set */
    listen(server_sockfd, 5);

    FD_ZERO(&readfds);
    FD_SET(server_sockfd, &readfds);

    while(1) {
        char ch;
        int fd;
        int nread;

        /* Must copy readfds every iteration because select() mutates it in place */
        testfds = readfds;

        printf("server waiting\n");
        result = select(FD_SETSIZE, &testfds, (fd_set *)0,
            (fd_set *)0, (struct timeval *)0);

        if(result < 1) {
            perror("server5");
            exit(1);
        }

        /* 3. Linearly scan from 0 to FD_SETSIZE (1024) to locate active FDs */
        for(fd = 0; fd < FD_SETSIZE; fd++) {
            if(FD_ISSET(fd, &testfds)) {

                /* Case A: Listening socket ready -> accept new client connection */
                if(fd == server_sockfd) {
                    client_len = sizeof(client_address);
                    client_sockfd = accept(server_sockfd,
                        (struct sockaddr *)&client_address, &client_len);
                    FD_SET(client_sockfd, &readfds);
                    printf("adding client on fd %d\n", client_sockfd);
                }
                /* Case B: Connected client socket ready -> check for EOF or payload */
                else {
                    ioctl(fd, FIONREAD, &nread);

                    if(nread == 0) {
                        /* Zero readable bytes indicates peer closed connection (EOF) */
                        close(fd);
                        FD_CLR(fd, &readfds);
                        printf("removing client on fd %d\n", fd);
                    }
                    else {
                        read(fd, &ch, 1);
                        sleep(5);
                        printf("serving client on fd %d\n", fd);
                        ch++;
                        write(fd, &ch, 1);
                    }
                }
            }
        }
    }
}

Key Mechanics & Architectural Limitations

testfds = readfds;
select() clears bits for all non-ready descriptors upon return. Passing readfds directly would erase tracked sockets, forcing a full bitmask copy every loop.
for(fd = 0; fd < FD_SETSIZE; ...)
Even with a single active client, the loop executes 1,024 FD_ISSET checks per wakeup and fails if any descriptor reaches 1024.
ioctl(fd, FIONREAD, &nread)
Queries how many bytes are queued in the socket receive buffer. A readable event with nread == 0 signals a clean TCP FIN disconnect, prompting close(fd) and FD_CLR().
Design Drawbacks
• No Graceful Shutdown: The infinite while(1) loop terminates abruptly on SIGINT without closing open sockets.
• Event-Loop Blocking: Calling sleep(5) inside a single-threaded event loop stalls all other clients for 5 full seconds.

Walkthrough 2 6. Refactored Version: poll() + signalfd()

This version preserves the single-process multiplexing design of server5.c while replacing select() with poll() to remove the 1,024-FD cap, and registering a signalfd() descriptor for SIGINT and SIGTERM to enable clean shutdown.

server5_poll_signalfd.c — Refactored with poll() & signalfd() 
#include <sys/types.h>
#include <sys/socket.h>
#include <sys/signalfd.h>
#include <sys/ioctl.h>
#include <netinet/in.h>
#include <signal.h>
#include <poll.h>
#include <unistd.h>
#include <stdio.h>
#include <stdlib.h>

#define MAX_CLIENTS 1024

int main(void) {
    int server_sockfd = socket(AF_INET, SOCK_STREAM, 0);
    struct sockaddr_in server_address = {
        .sin_family = AF_INET,
        .sin_addr.s_addr = htonl(INADDR_ANY),
        .sin_port = htons(9734)
    };
    bind(server_sockfd, (struct sockaddr *)&server_address, sizeof(server_address));
    listen(server_sockfd, 5);

    /* 1. Block SIGINT and SIGTERM, then wrap them in a signalfd */
    sigset_t mask;
    sigemptyset(&mask);
    sigaddset(&mask, SIGINT);
    sigaddset(&mask, SIGTERM);
    sigprocmask(SIG_BLOCK, &mask, NULL);

    int sfd = signalfd(-1, &mask, SFD_NONBLOCK | SFD_CLOEXEC);

    /* 2. Initialize pollfd array: [0] = listening socket, [1] = signalfd */
    struct pollfd fds[MAX_CLIENTS + 2];
    int nfds = 2;
    fds[0] = (struct pollfd){ .fd = server_sockfd, .events = POLLIN };
    fds[1] = (struct pollfd){ .fd = sfd,           .events = POLLIN };

    int running = 1;
    while (running) {
        printf("server waiting\n");
        if (poll(fds, nfds, -1) < 0) {
            perror("poll");
            break;
        }

        /* Iterate only across the active nfds entries (no sparse scanning) */
        for (int i = 0; i < nfds; i++) {
            if (!(fds[i].revents & POLLIN)) continue;

            if (fds[i].fd == sfd) {
                /* SIGINT or SIGTERM received: read siginfo and exit loop cleanly */
                struct signalfd_siginfo fdsi;
                read(sfd, &fdsi, sizeof(fdsi));
                printf("\nReceived signal %d, shutting down...\n", fdsi.ssi_signo);
                running = 0;
                break;
            } else if (fds[i].fd == server_sockfd) {
                /* Accept incoming client and append to pollfd array */
                struct sockaddr_in client_address;
                socklen_t client_len = sizeof(client_address);
                int client_sockfd = accept(server_sockfd,
                    (struct sockaddr *)&client_address, &client_len);
                if (client_sockfd >= 0 && nfds < MAX_CLIENTS + 2) {
                    fds[nfds++] = (struct pollfd){ .fd = client_sockfd, .events = POLLIN };
                    printf("adding client on fd %d\n", client_sockfd);
                }
            } else {
                /* Handle client data or disconnect */
                int nread = 0;
                ioctl(fds[i].fd, FIONREAD, &nread);
                if (nread == 0) {
                    printf("removing client on fd %d\n", fds[i].fd);
                    close(fds[i].fd);
                    fds[i] = fds[--nfds]; /* Swap-with-last for O(1) array compaction */
                    i--;                  /* Re-inspect the swapped-in element */
                } else {
                    char ch;
                    read(fds[i].fd, &ch, 1);
                    printf("serving client on fd %d\n", fds[i].fd);
                    ch++;
                    write(fds[i].fd, &ch, 1);
                }
            }
        }
    }

    /* 3. Unified cleanup: close all remaining client sockets, server socket, and signalfd */
    for (int i = 0; i < nfds; i++) close(fds[i].fd);
    return 0;
}

Implementation Highlights

sigprocmask(SIG_BLOCK, ...)
Target signals must be blocked before creating signalfd; otherwise, default signal dispositions (process termination) will trigger before signalfd can read them.
fds[i] = fds[--nfds]; i--;
O(1) Swap-and-Pop Removal: When a client disconnects at index i, the last active entry in fds is moved into slot i and nfds is decremented. Decrementing i ensures the newly moved entry is not skipped on the next iteration.
Unified Resource Cleanup
Upon receiving a termination signal, running becomes 0, exiting the main loop cleanly so a single for loop closes every active socket and signalfd without descriptor leaks.

Walkthrough 3 7. High-Concurrency Version: epoll + signalfd()

When scaling to thousands or tens of thousands of concurrent connections, migrating to epoll offloads descriptor tracking into the Linux kernel. User code no longer compacts arrays on disconnect, and each wakeup processes only truly active descriptors.

server5_epoll_signalfd.c — High-Concurrency epoll & signalfd() 
#include <sys/types.h>
#include <sys/socket.h>
#include <sys/epoll.h>
#include <sys/signalfd.h>
#include <netinet/in.h>
#include <signal.h>
#include <unistd.h>
#include <stdio.h>
#include <stdlib.h>

#define MAX_EVENTS 64

int main(void) {
    /* Create non-blocking listening socket with SO_REUSEADDR for fast restarts */
    int server_sockfd = socket(AF_INET, SOCK_STREAM | SOCK_NONBLOCK, 0);
    int opt = 1;
    setsockopt(server_sockfd, SOL_SOCKET, SO_REUSEADDR, &opt, sizeof(opt));

    struct sockaddr_in server_address = {
        .sin_family = AF_INET,
        .sin_addr.s_addr = htonl(INADDR_ANY),
        .sin_port = htons(9734)
    };
    bind(server_sockfd, (struct sockaddr *)&server_address, sizeof(server_address));
    listen(server_sockfd, 128);

    /* 1. Block SIGINT and SIGTERM, and create signalfd */
    sigset_t mask;
    sigemptyset(&mask);
    sigaddset(&mask, SIGINT);
    sigaddset(&mask, SIGTERM);
    sigprocmask(SIG_BLOCK, &mask, NULL);

    int sfd = signalfd(-1, &mask, SFD_NONBLOCK | SFD_CLOEXEC);

    /* 2. Create epoll instance and register server_sockfd and signalfd */
    int epfd = epoll_create1(EPOLL_CLOEXEC);
    struct epoll_event ev, events[MAX_EVENTS];

    ev.events = EPOLLIN;
    ev.data.fd = server_sockfd;
    epoll_ctl(epfd, EPOLL_CTL_ADD, server_sockfd, &ev);

    ev.events = EPOLLIN;
    ev.data.fd = sfd;
    epoll_ctl(epfd, EPOLL_CTL_ADD, sfd, &ev);

    int running = 1;
    while (running) {
        printf("server waiting\n");
        /* epoll_wait populates events[] ONLY with ready descriptors */
        int nfds = epoll_wait(epfd, events, MAX_EVENTS, -1);
        if (nfds < 0) {
            perror("epoll_wait");
            break;
        }

        for (int i = 0; i < nfds; i++) {
            int fd = events[i].data.fd;

            if (fd == sfd) {
                /* Signal event: break out of loop safely */
                struct signalfd_siginfo fdsi;
                read(sfd, &fdsi, sizeof(fdsi));
                printf("\nReceived signal %d, shutting down...\n", fdsi.ssi_signo);
                running = 0;
                break;
            } else if (fd == server_sockfd) {
                /* Accept new client as SOCK_NONBLOCK and register with epoll */
                struct sockaddr_in client_address;
                socklen_t client_len = sizeof(client_address);
                int client_sockfd = accept4(server_sockfd,
                    (struct sockaddr *)&client_address, &client_len, SOCK_NONBLOCK);
                if (client_sockfd >= 0) {
                    ev.events = EPOLLIN;
                    ev.data.fd = client_sockfd;
                    epoll_ctl(epfd, EPOLL_CTL_ADD, client_sockfd, &ev);
                    printf("adding client on fd %d\n", client_sockfd);
                }
            } else {
                /* Serve client payload or handle disconnect */
                char ch;
                ssize_t n = read(fd, &ch, 1);
                if (n <= 0) {
                    printf("removing client on fd %d\n", fd);
                    close(fd); /* Closing the FD automatically removes it from epoll */
                } else {
                    printf("serving client on fd %d\n", fd);
                    ch++;
                    write(fd, &ch, 1);
                }
            }
        }
    }

    close(sfd);
    close(server_sockfd);
    close(epfd);
    return 0;
}

Production Notes & Key Details

SO_REUSEADDR & SOCK_NONBLOCK
SO_REUSEADDR allows immediate rebinding to port 9734 if previous sockets remain in TIME_WAIT. Using SOCK_NONBLOCK and accept4(..., SOCK_NONBLOCK) ensures slow peers never block the single-threaded reactor loop.
What MAX_EVENTS 64 Means
MAX_EVENTS is not a cap on total concurrent connections—it is merely the batch size harvested per epoll_wait() call. If 200 sockets are ready simultaneously, the first call retrieves 64 and the next loop iteration immediately retrieves the rest without dropping any events.
Automatic Removal on close(fd)
Provided no duplicate file descriptors refer to the same underlying open file description (via dup/fork), calling close(fd) automatically unregisters the descriptor from the epoll red-black tree.
Architectural Selection Rule of Thumb

If your service must run portably across macOS, FreeBSD, and Linux with a few hundred concurrent connections, poll() + signalfd() (or a self-pipe) provides maximum portability and simplicity. When targeting Linux with thousands to tens of thousands of concurrent connections, epoll + signalfd() is the industry standard.
